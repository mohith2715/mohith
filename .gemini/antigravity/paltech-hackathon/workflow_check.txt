# Workflow Check

1. [x] **Application Root URL handling**: Navigating to `http://localhost:3000/` automatically redirects an unauthenticated user to `/login.html`.
2. [x] **Registration**: Clicking "Sign Up" on the login page navigates to `/register.html`. Submitting valid credentials successfully registers a new user and redirects them to the dashboard.
3. [x] **Authentication/Login**: Returning users can submit their credentials on `/login.html` and be seamlessly authenticated.
4. [x] **Dashboard (`index.html`) functionality**:
   - [x] Data binds correctly from the API. The number of ideas rendered dynamically matches `data.pagination.total`.
   - [x] The "Showing X results" text correctly reflects total ideas.
   - [x] Pagination controls correctly build dynamically (e.g., if total pages is 2, there are 2 buttons). Clicking them paginates properly.
   - [x] Search, Category, and Status filters correctly alter the URL parameters and re-fetch ideas.
   - [x] The "Dashboard" and "My Ideas" tabs successfully toggle. The "My Ideas" tab appends `mine=true` to fetch only the logged-in user's ideas.
5. [x] **Idea Creation**: Clicking "New Idea" correctly navigates to `/create.html`. Submitting an idea successfully saves it to the database and returns the user to the Dashboard.
6. [x] **Idea Details & Rating**: Clicking an idea successfully routes to `/idea.html?id=X`. The user can rate ideas they didn't create exactly once.
7. [x] **Reviewer Actions**: A reviewer can log in, view the reviewer-only panel on `idea.html`, and update the status safely according to the workflow rules.
8. [x] **Logout**: Clicking the "Logout" button on any authenticated screen immediately invalidates the session and redirects to the login screen.
